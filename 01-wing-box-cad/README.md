# Aircraft Wing Box CAD Assembly

A 3D SolidWorks CAD assembly of an aircraft wing box section (`Assem1.SLDASM`), modeling the primary load-carrying structural box formed by the upper and lower wing skins, front and rear spars, root rib, and joining L-bracket.

## Components

| File | Role |
| :--- | :--- |
| `Assem1.SLDASM` | Top-level wing box structural assembly |
| `Shell_Upper.SLDPRT` | Upper aerodynamic wing skin/shell |
| `Shell_Lower.SLDPRT` | Lower aerodynamic wing skin/shell |
| `SparFront.SLDPRT` | Front load-carrying wing spar |
| `SparBack.SLDPRT` | Rear load-carrying wing spar |
| `RootRib.SLDPRT` | Wing root rib transferring aerodynamic and torsional loads |
| `LBracket.SLDPRT` | Structural L-bracket joint/fastener component |

## How to Open

1. Keep all `.SLDPRT` part files in the same directory as `Assem1.SLDASM`.
2. Open `Assem1.SLDASM` in **SolidWorks** to inspect the full assembly, mates, and individual part geometries.
